# Rudra Digital Solutions Website

Static GitHub Pages website for Rudra ERP and Rudra Eye.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save.

## WhatsApp
Open `script.js` and replace `919999999999` with the business WhatsApp number including country code.
